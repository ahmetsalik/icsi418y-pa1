# Ahmet's Task Manager

## Name
Ahmet Salik

## Description
Ahmet's Task Manager is a simple interactive web application built with HTML, CSS, JavaScript and Git. Ahmet's Task manager allows users to create and manage tasks. Users can enter a task, select a priority level, mark tasks as completed, and delete tasks.

## How to Run
1. Download or clone the repository.
2. Open the project folder.
3. Open index.html in a web browser.
